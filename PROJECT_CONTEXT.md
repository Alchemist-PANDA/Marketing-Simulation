# Marketing Simulation Project Context

## Purpose
This project is a high-fidelity simulation environment for evaluating marketing strategies across different customer segments.

## Core Components
- **Agent Population**: 10 distinct customer personas with unique behavioral traits.
- **Campaign Engine**: Templates for various marketing channels (Email, Social, Search).
- **Decision Engine**: Logic for how agents respond to campaigns based on their traits and simulation parameters.
- **Simulation Runner**: Orchestrates the interaction between campaigns and agents over time.

## Key Goals
1. Validate marketing ROI for different segments.
2. Predict customer churn based on campaign fatigue.
3. Optimize budget allocation across channels.
